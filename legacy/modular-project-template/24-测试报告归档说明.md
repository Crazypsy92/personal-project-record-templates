# 测试报告归档

建议按日期和批次 ID 命名，例如： - `YYYY-MM-DD-RUN-UT-001.xml` -
`YYYY-MM-DD-RUN-UT-001.html` - `YYYY-MM-DD-RUN-GUI-001/` -
`YYYY-MM-DD-ACC-HW-001.md`

1.  优先保留机器生成的原始报告，并在 Markdown 批次记录中链接。
2.  大型原始数据、视频、模型不必直接放入 Git
    仓库；可放在受控外部存储，并登记路径、版本和校验信息。
3.  证据中如含公司机密、客户数据、账号或个人信息，先脱敏并确认授权。
4.  报告应能追溯到代码版本、测试环境和执行批次。
