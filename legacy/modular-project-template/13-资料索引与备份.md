## 长期保存建议

1.  文字优先使用 Markdown、TXT、CSV 等通用格式。
2.  图片使用常见格式，Markdown 尽量使用相对路径引用。
3.  复杂文档保留原件，必要时导出 PDF 阅读副本。
4.  大型数据、模型、视频可独立存储，并登记位置、版本和校验信息。
5.  不要提交密码、Token、API Key、私人证件或未经授权的公司资料。
6.  Git 历史不能替代独立备份。
7.  定期抽查备份能否打开，并尝试恢复到新目录。
